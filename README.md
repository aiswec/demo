# A project built with AISWEC

Open it in Suite, ask for what you want in plain words, approve the plan AISWEC writes,
and accept the changes when they are ready. Every irreversible step is your click.

`bun test` runs the checks AISWEC passes before changes reach you. `bun run build` writes the
page in `src/index.html` to `dist`, which is the preview each change gets before you accept it.
`.github/aiswec.yml` is how AISWEC behaves here, edited from Suite's Settings page.
